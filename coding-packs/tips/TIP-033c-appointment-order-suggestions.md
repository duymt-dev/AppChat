Current actor grants checked by discovery/runtime.

Historical unrelated contacts after relink are not included. Calendar detail projects same reader for exact appointment. Assistant receives typed appointment/conversation context and calls same read action/current source refs through discovery; it does not invent cards from model text.
5. Durable facts make cards survive reload/reconnect. Completion event may invalidate readers but is not the only delivery mechanism. New completed appointments appear by authorized refresh. No card for package appointment, undone completion, linked order or removed source. No automatic order, LLM call, notification spam or price mutation on complete/render/replay.
