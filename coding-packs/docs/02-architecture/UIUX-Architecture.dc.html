C1
Đăng nhập & Onboarding
Mở AppChat → Đã có tài khoản?
CÓ → Đăng nhập (SSO / Email) → Xác thực OTP / 2FA → Chọn Workspace → Dashboard

C2
Kết nối kênh (Zalo / Facebook / IG…)
Hộp thư / Cài đặt → Nhấn "Kết nối kênh" → Chọn nền tảng → Đăng nhập OAuth → Cấp quyền → Chọn Trang / OA → Đăng ký webhook → Đồng bộ hội thoại → Kênh hoạt động
C3
Nạp ví & thanh toán QR
Ví AppChat → Nhấn "Nạp tiền" → Nhập số tiền / gói → Chọn VietQR → Hiện mã QR → Quét & chuyển khoản → Cổng xác nhận (webhook) → Cộng số dư → Biên nhận
C4
Tạo chiến dịch Broadcast (Marketing)
Marketing → "Tạo chiến dịch" → Chọn kênh → Chọn tệp khách (segment / upload) → Soạn nội dung (AI gợi ý) → A/B test? → Kiểm tra số dư token → Lên lịch / Gửi ngay → Theo dõi báo cáo
C5
Xử lý hội thoại Inbox (AI → nhân viên)
Tin nhắn đến (kênh) → Hợp nhất vào Inbox → AI phân loại + trả lời → Đủ tự tin?
CÓ → AI xử lý / đóng → Ghi nhận CSAT
KHÔNG → Chuyển nhân viên → NV trả lời → Cần báo giá / ticket? → Tạo báo giá / ticket → Đóng + CSAT
